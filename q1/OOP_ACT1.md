# SG4 - Understanding Classes and Objects
## Sports
## This class represents the best sport of all time
## Properties
| Property | Data Type | Description |
|---|---|---|
| Name | string | Name of the sport |
| Inventor | string | Inventor of the sport |
| Games | int | Number of games in a regular season |
| Condition | boolean | Indicates if there will be a game |
## Methods
| Method | Description |
|---|---|| | |

| Start_Game | When the game will start |
| End_Game | When the game will end |
| Add_Point | Adds points to a team's score |
| Violation | What foul a player committed |
| Calculate_Point | What is the equivalent point of the shot made |
| Player_Time | How much a player has played |
| Player_Points | How much a player has scored|
| Player_Assists | How much a player has assisted anotehr player| 
| Player_Blocks | How much a player has legally stoped an attempted shot |
| Player_Steals | How much a player has legally stolen the ball from the enemy team player |
| Player_Turnovers | How much a player has turned over the ball to the enemy team |
